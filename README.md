# Professional Web Scraper Framework (Python)

Высокопроизводительный асинхронный парсер для сбора данных с защищенных ресурсов.

### Стек технологий:
* Python 3.10+
* aiohttp (асинхронные запросы для высокой скорости)
* BeautifulSoup4 / LXML (глубокий анализ HTML)
* Pandas (экспорт данных в Excel/CSV/JSON)

### Что реализовано:
1. Имитация реального браузера: обход простых систем защиты через ротацию заголовков (User-Agent).
2. Асинхронность: одновременная обработка до 100 страниц, что в 10 раз быстрее обычных скриптов.
3. Обработка исключений: скрипт не падает при потере соединения или изменении верстки сайта.
